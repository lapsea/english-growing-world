# 英语词句生长世界

人教版英语七年级上册教材同步学习平台（Web 应用），覆盖 Starter Units 1–3 与 Unit 1–7，提供教师、学生、家长三端协同的学习与管理的完整闭环。

## 功能总览

### 学生端
- **单元导学**：按单元浏览学习目标与核心句型
- **单词库**：全部核心词汇的搜索、多维筛选、真人发音 / 慢速跟读、收藏与掌握度管理
- **听力电台**：教材同步听力节目播放
- **阅读世界**：分级短文阅读与理解练习
- **写作工坊**：写作任务作答，支持保存草稿与查看教师批改
- **考试挑战**：限时答题，自动判分并生成成绩记录
- **错题本**：自动汇总练习与考试中的错题
- **学习进度**：等级经验、连续打卡、各模块学习时长统计
- **学习小游戏**：5 个单词类小游戏
- **小组排名**：学习小组积分排行榜

### 教师端
- **教师工作台**：班级整体学习情况速览
- **班级和学生**：学生列表、学习详情与学情跟踪
- **学习小组管理**：小组划分与调整
- **教学内容管理 / 题库管理**：单元内容与题目的增删改
- **作业布置**：向班级发布作业任务
- **作文批改**：批改学生作文并给出评语
- **考试挑战管理**：创建、发布、删除考试（删除考试时学生已有成绩记录级联删除）
- **班级学情 / 周挑战和排行榜**：成绩分析与排名管理

### 校务管理（教师端内）
- 校务概览、用户与角色（支持新增 / 编辑 / 删除账号）、家长绑定关系、教材与单元管理、班级数据、业务数据浏览器

### 家长端
- **学习概览**：孩子的学习时长、成绩、薄弱点
- **每周学习报告**：一周学习情况汇总

## 技术栈

- React 19 + TypeScript + Vite
- Tailwind CSS（Neubrutalism 风格设计系统）
- react-router-dom（Hash 路由）
- lucide-react 图标
- 数据层：本地模拟仓库，通过 localStorage 持久化，无需后端

## 快速开始

```bash
npm install
npm run dev
```

启动后浏览器访问 `http://localhost:5173`，在登录页选择角色入口即可进入对应端（内置演示账号）。

```bash
# 生产构建与本地预览
npm run build
npm run preview
```

## 数据说明

- 演示数据（用户、班级、单词、题目、成绩等）在首次启动时自动写入浏览器 localStorage
- 如需恢复初始演示数据：教师端 → 校务管理 → 业务数据浏览器 → 重置数据
- `scripts/` 目录为数据准备脚本（获取词典释义与发音音频等），运行应用无需执行

## 目录结构

```
src/
├── components/   # 通用 UI 与布局组件
├── pages/        # 各端页面（student / teacher / parent）
├── services/     # 数据仓库与发音服务
├── data/         # 演示种子数据（单元、单词、题目、阅读、听力、写作）
├── hooks/        # 通用 hooks
├── context/      # 全局状态（登录用户）
└── types/        # 类型定义
```

## 说明

本项目为教学演示项目，所有数据均为本地模拟数据，不涉及真实用户信息。
